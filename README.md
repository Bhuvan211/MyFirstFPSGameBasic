## 🎮 About The Project

**MyFirstFPSGameBasic** is a foundational First-Person Shooter (FPS) prototype designed to explore core game mechanics. Built using the Unity Engine, it implements essential features like player movement, camera control, weapon logic, and basic environment interaction. 

It serves as a stepping stone for more advanced game development mechanics, AI integrations, and level design.

### ✨ Key Features
- **Fluid FPS Controller:** Smooth walking, sprinting, and jumping mechanics.
- **Weapon System:** Basic hitscan/projectile shooting, reloading, and ammo management.
- **Dynamic Camera:** Mouse-look with adjustable sensitivity and recoil simulation.
- **Interactive Environment:** Simple targets and collision detection.
- **Clean UI:** Crosshair, health bar, and ammo counter integration.
